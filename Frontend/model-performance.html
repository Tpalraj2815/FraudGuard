How the Model Works

Main stages involved in transaction fraud classification.

01

Data Collection

Transaction information is collected, including amount, transaction type, location, device and transaction time.

02

Data Processing

Transaction features are prepared and transformed into the format required by the machine learning model.

03

Fraud Prediction

The Random Forest model analyses the input and returns a predicted transaction category and risk information.

Research and evaluation note: The dataset used in this project is synthetically generated. Its distribution and performance results should not be treated as proof of real-world banking fraud detection accuracy. Actual accuracy, precision, recall, F1-score and confusion matrix values must be obtained from the latest independent test evaluation before being presented as model results.
